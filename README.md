> That field was technically a shortcut — the highway was being boring and your suspension needed character development.

## How it works

`main.py` holds the GPS's excuse as a single string constant. When run, it
asserts the line is non-empty, exactly one line (no `\n` or `\r`), and
1–200 characters long, then writes it to `/output/entry.txt` with no
trailing newline. Python standard library only — no dependencies.
